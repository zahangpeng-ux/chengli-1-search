# 成理一号卫星数据平台改造计划

## Context

当前工程是 ASF Search UI 的本地化版本（Angular 21 + NgRx + OpenLayers + ngx-translate，已完成全站中文化）。用户希望在此 UI 基础上搭建成理一号卫星数据平台：

- 界面品牌、数据集信息改成「成理一号」；
- 目前没有成理一号的真实接口，相关功能先搭好占位结构，不急于实现；
- 不再请求原有 ASF 接口（搜索、登录、按需处理、下载、健康检查、横幅等）。

用户已确认：搜索接口做本地占位并隐藏外部功能入口；数据集列表只保留「成理一号」占位数据集；左上角生成新的 LOGO 图片。

## 目标

1. 页面标题、左上角标识、品牌文案改为「成理一号卫星数据平台」。
2. 数据集选择器中只出现「成理一号」，默认选中它；旧数据集定义保留在内部映射中，避免硬编码引用崩溃，但不再出现在可选列表。
3. 数据搜索链路改为本地占位：不发起任何 ASF 网络请求，搜索返回 0 条结果，UI 流程仍可正常操作。
4. 隐藏/禁用依赖 ASF 的功能入口：登录、按需处理、下载队列、基线/SBAS/形变/像对选择、衍生数据集、帮助中的 ASF 链接。
5. 更新版权/地图归属信息，移除 NASA GTM、Earthdata TopHat、ASF 跳转脚本。

### 2. 成理一号数据集

新建 `src/app/models/datasets/chengli-1.ts`，字段对齐现有 `Dataset` 结构：

- `id: 'CHENGLI-1'`，`name: '成理一号'`，`subName: 'CHENGLI-1'`
- `apiValue: { dataset: 'CHENGLI-1' }`
- `properties`: `DATE`、`FLIGHT_DIRECTION`、`PATH`、`FRAME`、`PLATFORM`
- `productTypes`: L0/L1/L2/L3 四类占位产品（如“L1 标准产品”）
- `platforms`: `[{ displayName: '成理一号', apiValue: 'CHENGLI-1' }]`
- `polarizations: []`、`beamModes: []`，避免展示 SAR 专属筛选
- `date: { start: new Date('2024/01/01 00:00:00 UTC') }`
- `source: { name: '成都理工大学', url: null }`
- `frequency: '待定'`
- `infoUrl: ''`、`citationUrl: ''`
- `description: 'CHENGLI_1_DESC'`
- `icon: '/assets/icons/satellite_alt_black_48dp.svg'`

修改 `src/app/models/dataset.model.ts`：

- `datasetList` 只保留 `chengli_1`（选择器、偏好设置等只显示它）；
- `datasets` 映射由「原有全部数据集 + 成理一号」构建，保证 `models.datasets['SENTINEL-1 INTERFERogram (BETA)']` 等内部硬编码引用不返回 `undefined`；
- 新增 `getDataset(id)`，未知 id 回退到成理一号；
- `datasetIds` 仍由 `datasetList` 生成（只有成理一号）。

修改 `src/app/models/datasets/index.ts` 导出新数据集。

### 3. 默认数据集与状态回退

修改 `src/app/store/filters/filters.reducer.ts`：

- `initState.selectedDatasetId` 改为 `PLATFORM.datasetId`；
- `SET_SELECTED_DATASET` 中未知数据集回退为成理一号；
- `SET_FILTERS_SIMILAR_TO` 的 `selectedDatasetId` 只接受 `datasetIds` 中的值；
- 恢复已保存搜索时的 `models.datasetList.filter(...)[0]` 改为 `models.getDataset(...)`，避免旧搜索把数据集取成 `undefined` 后访问 `.platforms` 崩溃。

修改 `src/app/services/dataset-for-product.service.ts`：保留原有匹配逻辑，但所有按 id 取数据集处改用 `models.getDataset()`，默认回退到 `datasetList[0]`。

### 4. 搜索接口本地占位

重写 `src/app/services/asf-api.service.ts` 的请求方法，不再注入 `HttpClient`：

- `query<T>(params)`：`output === 'COUNT'` 时返回 `of(0)`；其余返回 `of({ results: [] })`；
- `miniQuery()`：`of([])`；
- `queryUrlFrom()`：返回空串（对应导出/复制入口将隐藏或显示占位）；
- `collections()`：返回 `[]`；
- `loadMissions$`：`of({})`；
- `missionSearch()`：`of({ result: [] })`；
- `upload()`：`of({})`；
- `validate()`：`of({ valid: true })`；
- `getNisarOrbitEphemera()`：`of([])`；
- `health()`：`of({ ASFSearchAPI: { ok: true }, CMRSearchAPI: {} })`，且不再被调用。

保持方法签名和类名不变，避免大范围改动调用方。

修改 `src/app/services/env.ts`：把 `api/auth/urs/banner/user_data/bulk_download/displacement_api` 全部置为空字符串，`defaultEnv` 保持不变。这样即使有遗漏调用也不会打到 ASF。同步检查 `src/app/services/envs/` 中是否还有 ASF 域名（若有则一并清空）。

在 `src/app/services/auth.service.ts` 中，当 `PLATFORM.features.auth === false` 时：`getUser()`、`login$()`、`logout$()` 直接返回 `of(null)`。

在 `src/app/services/banner-api.service.ts` 中，当 `banner` 地址为空时 `load()` 直接返回 `of({ banners: [], systime: '' })`。

### 5. 启动阶段不再请求外部接口

## 已知限制

- 搜索、数据集参数、产品类型均为占位，真实接口接入时只需替换 `AsfApiService` 的查询方法与 `chengli-1.ts` 数据集定义。
- 旧数据集仍保留在内部 `datasets` 映射中用于兼容硬编码引用，但用户不可见。
- 若未来恢复登录/下载/按需处理，只需打开 `PLATFORM.features` 对应开关并补回接口实现。
